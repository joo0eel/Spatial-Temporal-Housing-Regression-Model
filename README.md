# Spatial-Temporal Housing Regression Model🏠📊

An end-to-end Automated Valuation Model (AVM) built with **Python** and **Random Forest Regression** to predict residential real estate market values. 

## 🚀 Key Features
* **Random Forest Regressor:** Leveraged ensemble tree-based models to handle complex feature interactions and non-linear data.
* **Feature Engineering:** Implemented data pipelines to clean, encode, and scale critical structural and geographic indicators.
* **Hyperparameter Tuning:** Optimized model performance using Scikit-Learn's tuning techniques to eliminate overfitting.
